# Contributing

Thanks for helping build an independent alternative. The project is in discovery and planning; target-specific implementation should wait until requirements are supported by evidence and the project license is selected.

## Before opening a change

1. Read `README.md`, `AGENTS.md`, and the relevant documents in `docs/`.
2. Keep target APKs, proprietary decompiler output, credentials, personal data, and raw network captures out of commits. Summarize only the minimum sanitized evidence needed to support a requirement.
3. Link target-specific behavior claims to evidence IDs in `docs/analysis/evidence-ledger.md`. Mark hypotheses and unknowns clearly.
4. Do not submit copied app code, logos, screenshots, icons, text, private keys, or third-party assets without clear permission and provenance.
5. For implementation changes, include tests for the documented behavior and update the requirements, architecture, and testing documents as needed.

## Pull requests

Describe the user-visible behavior, evidence or rationale, tests run, privacy/security impact, and any new dependencies. State known limitations and unresolved questions. Do not claim parity where behavior has not been tested.

## Licensing

The repository currently has no `LICENSE` file. A license must be selected before the project can be redistributed as open source. Until then, do not assume your contribution or this repository is available under an open-source license. See `docs/legal-and-provenance.md`.
