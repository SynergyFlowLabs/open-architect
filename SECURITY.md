# Security policy

This project is not yet released and has no supported production build. Security reports should not include APKs, credentials, private user data, or unredacted traffic captures in public issues.

## Reporting a vulnerability

Use GitHub's **private vulnerability reporting** for this repository if it is enabled. If it is not enabled, contact a repository maintainer through a private channel listed on the repository profile and ask for a secure reporting route; do not publish exploit details first. Maintainers should enable private reporting and add a monitored contact before publishing a release.

Please include the affected commit or release, impact, reproduction steps that do not expose third-party data, and any suggested mitigation. Allow maintainers time to investigate and coordinate a fix before public disclosure.

## Scope

Reports may concern this project's future code, build/release process, dependency chain, data handling, or analysis tooling integration. The target APK and REA itself are separate projects; report vulnerabilities in those projects to their maintainers.
